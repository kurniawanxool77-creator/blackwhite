# Antigravity & Gemini Project Directives

This project enforces strict standards against AI code bloat and low-quality template design.

- **Ponytail Discipline**: Follow [ponytail.md](file:///c:/Users/linta/Documents/Pemograman/Sistem%20Barcode/ponytail.md). Always question whether new code, wrappers, or dependencies are genuinely needed before writing them.
- **Architectural Modularity**: Keep files under 400 lines. Extract modals, dialogs, complex filters, and table sections into `components/`.
- **Anti-AI Slop**: Follow the enterprise UI standards in [.agents/rules/anti-ai-slop-ui.md](file:///c:/Users/linta/Documents/Pemograman/Sistem%20Barcode/.agents/rules/anti-ai-slop-ui.md). Crisp edges (`rounded`/`rounded-md`), corporate aesthetics, no gaudy pastel bubbles.
- **Code Quality**: Verify changes with static checks and test builds before declaring completion.
